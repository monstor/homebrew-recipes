## 🍻 版本歷史

### v1 - Low Residual Sugar([檔案](./v1-low-residual-sugar.html)) ★ 當前版本
**低殘糖,不甜膩**

傳統 milkshake IPA 靠大量乳糖製造甜潤濃稠,但容易甜膩黏。這版改用「蛋白質撐濃稠 + 少量乳糖留圓潤 + 無糖果泥給果香」的策略:
- 乳糖大減(只留 15g/6L)
- 濃稠改靠燕麥+小麥的高蛋白骨架
- 水果用無糖果泥(芒果+百香果)

**配方重點**:
- 穀物:Extra Pale 1.8kg + Wheat 700g + 燕麥 700g
- 乳糖 15g + 香草莢(可選)
- 酒花:Magnum 3g + Citra/Mosaic(whirlpool + dry hop)
- 芒果泥 300g + 百香果泥 100g(無糖)

## 🛡️ 封裝端抗氧化(共通標準)

完整說明 → [**共通封裝端抗氧化 SOP**](../shared/antioxidant-packaging-sop.html)

本配方走**強制碳酸 / KEG**,可以加抗氧化劑:

| 藥劑 | **6L 批**(本配方) | 10L 批 |
|---|---|---|
| L-抗壞血酸(維生素C) | **0.18g** | 0.3g |
| 焦亞硫酸鉀 KMS | **0.15g** | 0.25g |

- **⚠️ VC 必須配 KMS,不可單用**:抗壞血酸抓氧會產生 H₂O₂,遇酒中微量鐵/銅走 **Fenton 反應**生成羥自由基 → **氧化得比不加還兇**。KMS 的工作就是收掉 H₂O₂。**只有 VC 沒有 KMS → 寧可兩個都不加。**
- **做法**:轉桶時把兩者溶進 20-30ml 冷開水 → **倒進 keg 底部** → CO₂ purge ×3 → 底部入酒(酒一灌進來就被保護,不必事後開蓋)。
- **不會有硫味**:SO₂ 大半立刻結合成無味態;≈14 ppm 總 SO₂ 遠低於感知門檻(~20-25 ppm 游離),且 Ale 酵母本來就自產 5-20 ppm。**上限 KMS 0.5g/10L**。
- **權重**:藥劑是**保險(20%)**,**低氧流程才是主力(80%)**——keg 三次 purge、底部入酒不濺、頂空最小、趁鮮喝。
