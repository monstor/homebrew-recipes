## 🍻 版本歷史

### v1 - Low Residual Sugar([檔案](./v1-low-residual-sugar.html)) ★ 當前版本
**低殘糖,不甜膩**

傳統 milkshake IPA 靠大量乳糖製造甜潤濃稠,但容易甜膩黏。這版改用「蛋白質撐濃稠 + 少量乳糖留圓潤 + 無糖果泥給果香」的策略:
- 乳糖大減(只留 15g/6L)
- 濃稠改靠燕麥+小麥的高蛋白骨架
- 水果用無糖果泥(芒果+百香果)

**配方重點**:
- 穀物:Extra Pale 1.8kg + Wheat 700g + 燕麥 700g
- 乳糖 15g + 香草莢(可選)
- 酒花:Magnum 3g + Citra/Mosaic(whirlpool + dry hop)
- 芒果泥 300g + 百香果泥 100g(無糖)
