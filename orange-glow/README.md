## 🍻 版本歷史

### v1 - Original([檔案](./v1-original.html))
原始配方。OG 1.078 / ABV 7.8-8.2% 的高強度 DDH NEIPA,使用 Extra Pale Ale Malt 取代 Maris Otter,兩段 Dry Hop(Day 4-5 + Day 8-9 冷崩前)。

**潛在問題(基於妃子起笑 v1 的教訓推論):**
- 第二段 Dry Hop 在 FG 已到位才投,跟妃子起笑 v1 同樣失控路徑
- OG 1.078 糊精多,hop creep 啃糊精會比妃子起笑(FG 1.014→1.008)更兇
- 8% ABV 酵母疲勞,雙乙醯清除能力差
- 雙包 Verdant 成本高

**未實際釀造,直接升級到 v2。**

### v2 - Lessons Learned Integration([檔案](./v2-lessons-learned.html))
**核心:全面套用妃子起笑實戰教訓**

13 項更新:

1. 單段 Dry Hop 卡進主發酵期(Day 3-4,比重 1.045-1.035 時投全部 112g)
2. 綠燈確認 SOP(連兩次比重不動 + 強迫雙乙醯測試)
3. 強迫雙乙醯測試方法
4. 一包 Verdant + 2L Starter(取代 2 包,省成本)
5. Fermaid-K → Fermaid-O(不抑制酯類,保留 NEIPA 果香)
6. 省略 Cold Crash
7. 虹吸轉桶完整 SOP
8. 低壓慢飽和強制碳酸(禁止 30 PSI 猛搖)
9. 取消瓶內二發選項(8% ABV 酵母太疲勞)
10. 時程延長 14 天 → 18-20 天
11. 最佳賞味期 2-3 週警告
12. 糖化降到 65°C
13. Day 3 比重檢查 fallback 邏輯

### v2.1 - Starter Fix + ALDC Integration([檔案](./v2.1-starter-fix-aldc.html))
**核心:v2 的兩個小修正**

1. **修正 Starter 容器尺寸**:v2 原本錯誤寫「2L 玻璃瓶」,正確應該是「4-5L 容器裝 2L 麥汁」(泡沫會佔麥汁高度 30-50%)。
   - 容器選項:4L 廣口玻璃罐(200-400 元)/ 5L 硼矽酸鹽錐形瓶(800-1500 元)/ 4L 大泡菜罐(200 元)

2. **整合 ALDC(Maturex L)SOP**:投酵母當下加 0.2-0.3ml,從化學源頭阻斷雙乙醯生成。
   - 取量方法:胰島素注射器(藥局幾十塊,1ml 細分 100 格)或稀釋法(10% 濃度)
   - 對 DDH/高 ABV 特別有價值
   - Fermaid-O 在 v2.1 改回 Fermaid-K(因為買不到 Fermaid-O)

**v2 的其他核心改造(單段 Dry Hop、綠燈確認、虹吸轉桶、低壓慢飽和、省略 Cold Crash 等)全部保留。**

### v2.2 - Whirlpool + Fermaid Tuning([檔案](./v2.2-whirlpool-fermaid.html))
**核心:兩個往「更果汁、更柔和」方向的風味微調 + 一項數字修正**

不動發酵流程,只調兩個直接影響 NEIPA 果香的細節:

1. **旋渦溫度 80°C → 75°C**:高溫旋渦會稍微烤掉嬌嫩的酒花精油、也多帶苦。降到 75°C 香氣保留更好、苦感更柔,IBU 更穩定落在 25-30 低區(75°C 仍在巴氏滅菌區間,食安沒問題)
2. **營養劑改 Fermaid-O 5g 為主**:Fermaid-O 是純有機氮源、不含 DAP,不會抑制果香酯類(商業 NEIPA 廠首選)。v2.1 因買不到才退用 Fermaid-K,v2.2 改回 Fermaid-O 為主、**Fermaid-K 降為備選**(買不到 O 時用 3g)
3. **修正酒花總量**:從 v1 起表頭一直誤寫「168g」,實際是 Magnum 6 + 旋渦 56 + Dry Hop 112 = **174g**(漏算了苦花 Magnum 6g)

**v2.1 的其他設計(Starter 4-5L 修正、ALDC SOP、單段 Dry Hop、綠燈確認、虹吸轉桶、低壓慢飽和)全部保留。**

### v2.3 - DME Base + Less Oats([檔案](./v2.3-dme.html))
**核心:換厚度來源 —— DME 取代葡萄糖 + 燕麥減量**

配方/流程變更,其餘完全沿用 v2.2:

- **葡萄糖 200g → 大麥 DME 220g**:葡萄糖 100% 可發酵、把酒拉乾;DME 約 75-80% 可發酵,留糊精與麥芽風味 → 麥香骨架。starter 本來就用 DME,**一物兩用、免另買葡萄糖**
- **燕麥 1000g → 800g(Extra Pale 維持 2000g)**:減 β-聚葡萄糖 → 口感不要太油滑、糖化洗槽更順、降卡槽風險。穀物降到 4.8kg,OG 可能略低 1-2 點(可接受,或靠 DME/補基礎麥芽拉回)
- **Fermaid-O 改投酵母時加(不煮)**:有機氮要靠酵母在發酵期吸收,煮沸用不到那優勢。投酵母當下跟 ALDC 一起撒入。(備選 Fermaid-K 才維持煮沸末加,因 DAP 即時可用)
- **整體走向**:從「滑而厚」變「乾淨有支撐」——DME 的麥香骨架取代葡萄糖的乾瘦,燕麥減量收掉油滑,兩者方向一致
- **數據**:FG 1.015-1.017、ABV 7.7-8.1%、EBC 13-15(略深);OG 維持 1.075-1.078;haze 有小麥+酒花撐著幾乎不變
- 旋渦 75°C、單段 Dry Hop、Starter、ALDC、綠燈、虹吸轉桶、低壓慢飽和全部不變
- 微調方向:偏厚/偏甜 → DME 降回 ~180g;太瘦/haze 不夠 → 燕麥加回 900-1000g

### v2.4 - Golden Promise Base + Pomona([檔案](./v2.4-golden-promise.html)) ★ 當前版本
**核心:基麥換 Golden Promise + 酒花改單一 Pomona,整體轉向英系 juicy;穀物整理成 1kg 整數單位**

動基麥與酒花品種,其餘(糖化 65°C、旋渦 75°C、Fermaid-O、單段 Dry Hop 時程與技法、Starter、ALDC、綠燈、虹吸轉桶、低壓慢飽和)完全沿用 v2.3:

- **Extra Pale 2kg → Golden Promise 2kg(1:1 換基麥)**:GP 是蘇格蘭傳統 2-row,蛋白質略高、帶餅乾/麵包柔甜蜜香 → 酒體更柔順綿密、泡沫更飽滿,跟 Verdant 酵母加分。英系 NEIPA 廠(Verdant、Cloudwater)的愛用基底
- **酒花全面改單一 Pomona(取代 Citra/Amarillo/Galaxy)**:旋渦 Pomona 56g + 乾投 Pomona 112g,苦花 Magnum 6g 不變,總量維持 174g。Pomona 是英系酒花,香型走**哈密瓜/水梨/草莓糖/淡熱帶**,跟 GP 英系麥香同調。⚠️ **橘香會明顯轉淡**,名字雖沿用 Orange Glow,風味已是另一種個性(實飲後想正名可另開新酒名)
- **穀物收斂成 1kg 整數:GP 2 / Munich 1 / Wheat 1 / 燕麥 1 = 5kg**:Munich 維持 1kg(撐金黃酒色與麥香層次)、燕麥由 800g 回到 1kg(多給一點綿密),採購好算
- **大麥 DME 維持 180g(煮沸末,以 g 計、非麥芽)**:跟 starter 共用、補一點 OG。穀物到 5kg,OG 回到 v2.3 水準
- **整體走向**:從 v2.3 的「美系橘香 + 乾淨有支撐」變「英系瓜果 juicy + 柔順綿密」。EBC 14-16、FG 高 1-2 點收口沒那麼乾——正合這風格
- **數據**:OG 1.075-1.078、FG 1.016-1.018、ABV 7.6-8.0%、EBC 14-16
- 微調方向:Pomona 太單薄 → 乾投加量或補一支搭配花(Citra 增柑橘亮度);偏甜偏厚 → 燕麥回 800g 或 Munich 降到 0.5kg
