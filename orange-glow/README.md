### v1 - Original([檔案](./v1-original.html))
原始配方。OG 1.078 / ABV 7.8-8.2% 的高強度 DDH NEIPA,使用 Extra Pale Ale Malt 取代 Maris Otter,兩段 Dry Hop(Day 4-5 + Day 8-9 冷崩前)。

**潛在問題(基於妃子起笑 v1 的教訓推論):**
- 第二段 Dry Hop 在 FG 已到位才投,跟妃子起笑 v1 同樣失控路徑
- OG 1.078 糊精多,hop creep 啃糊精會比妃子起笑(FG 1.014→1.008)更兇
- 8% ABV 酵母疲勞,雙乙醯清除能力差
- 雙包 Verdant 成本高

**未實際釀造,直接升級到 v2。**

### v2.2 - Whirlpool + Fermaid Tuning([檔案](./v2.2-whirlpool-fermaid.html))
**核心:兩個往「更果汁、更柔和」方向的風味微調 + 一項數字修正**

不動發酵流程,只調兩個直接影響 NEIPA 果香的細節:

1. **旋渦溫度 80°C → 75°C**:高溫旋渦會稍微烤掉嬌嫩的酒花精油、也多帶苦。降到 75°C 香氣保留更好、苦感更柔,IBU 更穩定落在 25-30 低區(75°C 仍在巴氏滅菌區間,食安沒問題)
2. **營養劑改 Fermaid-O 5g 為主**:Fermaid-O 是純有機氮源、不含 DAP,不會抑制果香酯類(商業 NEIPA 廠首選)。v2.1 因買不到才退用 Fermaid-K,v2.2 改回 Fermaid-O 為主、**Fermaid-K 降為備選**(買不到 O 時用 3g)
3. **修正酒花總量**:從 v1 起表頭一直誤寫「168g」,實際是 Magnum 6 + 旋渦 56 + Dry Hop 112 = **174g**(漏算了苦花 Magnum 6g)

**v2.1 的其他設計(Starter 4-5L 修正、ALDC SOP、單段 Dry Hop、綠燈確認、虹吸轉桶、低壓慢飽和)全部保留。**

### v2.3 - DME Base + Less Oats([檔案](./v2.3-dme.html))
**核心:換厚度來源 —— DME 取代葡萄糖 + 燕麥減量**

配方/流程變更,其餘完全沿用 v2.2:

- **葡萄糖 200g → 大麥 DME 220g**:葡萄糖 100% 可發酵、把酒拉乾;DME 約 75-80% 可發酵,留糊精與麥芽風味 → 麥香骨架。starter 本來就用 DME,**一物兩用、免另買葡萄糖**
- **燕麥 1000g → 800g(Extra Pale 維持 2000g)**:減 β-聚葡萄糖 → 口感不要太油滑、糖化洗槽更順、降卡槽風險。穀物降到 4.8kg,OG 可能略低 1-2 點(可接受,或靠 DME/補基礎麥芽拉回)
- **Fermaid-O 改投酵母時加(不煮)、分兩次**:有機氮要靠酵母在發酵期分段吸收,煮沸用不到那優勢。投酵母當下 2.5g 跟 ALDC 一起撒入、投後約 24h 再補 2.5g(更貼酵母需氮曲線,高 OG + 單包時發酵更穩、果香更飽)。(備選 Fermaid-K 才維持煮沸末加,因 DAP 即時可用)
- **整體走向**:從「滑而厚」變「乾淨有支撐」——DME 的麥香骨架取代葡萄糖的乾瘦,燕麥減量收掉油滑,兩者方向一致
- **數據**:FG 1.015-1.017、ABV 7.7-8.1%、EBC 13-15(略深);OG 維持 1.075-1.078;haze 有小麥+酒花撐著幾乎不變
- 旋渦 75°C、單段 Dry Hop、Starter、ALDC、綠燈、虹吸轉桶、低壓慢飽和全部不變
- 微調方向:偏厚/偏甜 → DME 降回 ~180g;太瘦/haze 不夠 → 燕麥加回 900-1000g

### v2.4 - Golden Promise Base + LalBrew Pomona([檔案](./v2.4-golden-promise.html))
**核心:基麥換 Golden Promise + 酵母換 LalBrew Pomona,整體更英系 juicy、果香更外放;主穀整理成 1kg 整數單位、燕麥 0.8kg 控酒體**

動基麥與酵母,其餘(糖化 65°C、旋渦 75°C、Fermaid-O、單段 Dry Hop、ALDC、綠燈、虹吸轉桶、低壓慢飽和、**酒花配方 Citra/Amarillo/Galaxy**)完全沿用 v2.3:

- **Extra Pale 2kg → Golden Promise 2kg(1:1 換基麥)**:GP 是蘇格蘭傳統 2-row,蛋白質略高、帶餅乾/麵包柔甜蜜香 → 酒體更柔順綿密、泡沫更飽滿。英系 NEIPA 廠(Verdant、Cloudwater)的愛用基底
- **酵母 Verdant IPA → LalBrew Pomona(乾酵母)**:Lallemand × Escarpment 的現代 hybrid IPA 酵母,專為高 ABV、重酒花 IPA 設計。**高生物轉化**——把乾投酒花的硫醇前驅物轉成桃/柑橘/熱帶香、高發酵度但不啃糊精、穩定 haze、耐操。跟本配方「發酵期單段乾投」是絕配:酵母一邊發酵一邊做生物轉化,把 Citra/Galaxy 的橘香與熱帶感放得比 Verdant 更外放。**⚠️ 但 Pomona 發酵極快(首批 #0008 第 3 天就 1.016),1.045-1.035 的乾投窗口約落在 Day 1-2,要比 Verdant(Day 3-4)更早乾投——從 Day 1 起就量比重、進區間立刻投,別等 Day 3。****標準走 1 包 + 投酵母前高壓純氧 60-90s 直投、免 starter**;想保險再上 2 包或養 2L starter
- **主穀 1kg 整數 + 燕麥 0.8kg:GP 2 / Munich 1 / Wheat 1 / 燕麥 0.8 = 4.8kg**:GP/Munich/Wheat 取整好採購,燕麥維持 0.8kg 收掉油滑、避免太厚太甜(Munich 撐橘金酒色與麥香層次)
- **大麥 DME 維持 180g(煮沸末,以 g 計、非麥芽)**:跟 starter 共用、補一點 OG。穀物 4.8kg + DME,OG 維持 v2.3 水準
- **整體走向**:GP 給「柔順綿密、泡沫飽滿」的英系酒體,Pomona 把熱帶柑橘果香放大、haze 更穩定。橘香主軸(Citra/Amarillo/Galaxy)不變、反而更外放
- **數據**:OG 1.075-1.078、FG 1.015-1.017、ABV 7.7-8.1%、EBC 14-16(GP 略深)
- 微調方向:想更厚更綿密/泡沫更持久 → 燕麥加回 1kg;想更乾淨的酒花清晰度 → GP 與 Extra Pale 各半

### v2.5 - Clean NEIPA([檔案](./v2.5-clean-neipa.html))(#0009 首釀,意外變淺金 5.8%)
**核心:清爽版 NEIPA + 全面修正 #0007 過苦**

從 v2.4「高 OG 厚實 DDH」轉向**乾淨清爽而且夠香**:苦味靠**流程**控(不靠砍酒花),香氣靠 **Whirlpool(口中果汁感)+ 雙段 Dry hop(鼻子的香)**疊出來。

> **注意:首釀批次 = #0009。**本版已依 #0007/#0008 實飲回饋多次修訂(雙段乾投衝香、IBU 25-30、pH/石膏/糖化溫三改)。**⚠️ 首釀實際穀物:Extra Pale 3.0 + 小麥 1.0 + 燕麥 0.5 = 4.5kg,無 Munich → 淺稻草金(非橘);橘色下批補 Munich 再現。**

- **🍺 #0008 實飲回饋 → 最新修訂(降苦 + 果汁感)**:實飲「**有果汁感,但還是被大量苦味蓋過**」。關鍵:#0008 苦花只有 Magnum 6g 且準時加(無 #0007 那些失誤)→ **苦不是酒花量的問題**。四個真兇,逐一處理:
  - **成酒 pH 3.83 太酸**(糖化醪僅 4.76,目標 5.2-5.4)→ 苦味尖銳咬喉。**❌ 舊版叫你「滴磷酸」是反的** —— 這支水又軟又低鹼(KH 40),要**加小蘇打**把 mash pH 拉到 5.2-5.4、成酒 4.2-4.5,**絕不加酸**
  - **石膏(硫酸鹽)放大苦味**、又是酸性鹽 → **石膏歸零**,鈣只由 CaCl₂ 提供
  - **太乾**(FG 1.015 配 9.8%)→ 沒有殘糖墊住酒花、苦味裸露 → **糖化改回 67°C**,FG 收在 1.014-1.016
  - **9.8% 酒精灼熱感被讀成苦** → v2.5 降到 OG ~1.064 / **ABV ~6.5-7.0%**(遠低於 9.8%,清爽)
  - **乾投維持 112g 不動** —— 砍酒花只會砍掉香氣,苦從源頭治

- **酒花處理(修 #0007 太苦)**:苦花 Magnum 6g 準時 60min 加、裝濾袋、**煮完撈出**(#0007 忘加→補煮一小時 + 沒撈是過苦主因);**Whirlpool** 78°C(71-82)香花 84g(濾袋)靜置 20-30min 後撈出;**dry hop 限時撈出**(#0007 泡到發酵完→冷側粗糙苦 humulinone/多酚)
  - **📌 更正:#0007 有確實做 Whirlpool**(早期曾誤判為「疑似漏做」)。加上 dry hop 也投滿 112g、酒花真空冷凍保存良好 → **香氣不足不是漏做步驟,是結構性問題** → 解法是 **DH2**,不是「補做 whirlpool」
- **★ 雙段乾投(共 112g,修 #0007/#0008「不夠香」)**:
  - **DH1 56g**(Nelson 28 + Strata 28)—— 活躍發酵期投(OG 降一半 ~1.037,**混投 Pomona 主導→Day 1 起量**),做生物轉化;泡 3-5 天撈出
  - **DH2 56g**(Peacharine 28 + Mosaic 28)—— **綠燈確認後才投**,18-20°C 泡 2-3 天
  - **為什麼要 DH2**:活躍發酵的 CO₂ 會把揮發性酒花香氣沖走(**CO₂ scrubbing**),這是 #0007/#0008 香氣不足的結構性原因。DH2 在發酵停止後投 → **零沖刷 → 「鼻子的香」完整留住**。這是頂級 NEIPA 廠的標準做法
  - **⚠️ DH2 後必須再確認連兩次比重不動才轉桶**(DH2 會帶來第二波 hop creep);前提是走 **KEG 強制碳酸**(keg 不會炸瓶)
- **IBU 回到 ~25-30(不再壓到 ~20)**:#0007 熟成 3 週後**苦度自行收斂到「剛好」、燒喉感消失**,證明「過苦」大半是**新酒問題 + 流程失誤**,不是配方問題 → **降苦交給流程,不犧牲香氣**
- **穀物**:**基麥 Extra Pale Ale Malt 3.0kg(首釀實購,非 GP)** + 小麥 1.0kg + **燕麥 0.5kg 撐 haze**(視覺濃霧;#0008 是 0.8kg,減量控絲滑);不加 DME/Maltodextrin;**糖化維持 67°C**。**Extra Pale 3.0 / Wheat 1.0 / 燕麥 0.5 = 4.5kg(無 Munich)**
  - **🌾 基麥 Extra Pale vs Golden Promise**:Extra Pale 更乾淨中性,少了 GP 的餅乾麥甜與綿密酒體;走回 v2.3 的乾淨基底風
  - **🌫️ 霧度(視覺重點)**:小麥、GP 已採購定量(小麥 1.0kg),唯一可調的是燕麥 → **燕麥加回 0.5kg 補濃霧**(#0008 是 0.8kg,減量以控絲滑)。小麥+燕麥都給霧,燕麥額外帶絲滑,取半量是折衷
  - **🎨 這批無 Munich → 淺稻草金(非橘,EBC 5-7)**:Munich 是橘金色唯一來源,首釀未採購 → 成酒淺黃。**但視覺賣點是「濃霧不透光」(靠小麥+燕麥+乾投),不受無 Munich 影響**——很多頂級 NEIPA 就是淺金濃霧。橘色下批補 Munich 1.0kg 即現。⚠️ 別臨時拿結晶/焦糖/烘焙麥補色(帶甜/焦味毀果汁感)
- **水質 / pH(最關鍵)**:**石膏歸零**、只用 **CaCl₂ 1.5g**(鈣 ~50ppm);**pH 計換 SR44 電池 + 4.01/7.00 標準液校正**;糖化醪取樣**冷卻到 20-25°C 再量**,**低於 5.2 就加小蘇打**(先 1g、攪勻、再測,上限 ~3g);**❌ 絕不加磷酸/乳酸**。成酒目標 pH **4.2-4.5**
- **抗氧化劑(封裝端新增,→ [共通 SOP](../shared/antioxidant-packaging-sop.html))**:轉桶時在接收 keg 底部先放 **L-抗壞血酸 0.3g(30 mg/L)+ 焦亞硫酸鉀 KMS 0.25g(25 mg/L)**,溶進 20-30ml 冷開水 → purge ×3 → 底部入酒。**兩者必須成對**:抗壞血酸抓氧時產生 H₂O₂,遇酒中微量鐵/銅會走 **Fenton 反應**生成羥自由基 → **氧化得比不加還兇**;KMS 的工作就是收掉 H₂O₂。**只有 VC 沒有 KMS → 寧可兩個都不加。**
  - 不會有硫味:SO₂ 進酒大半立刻結合成無味的結合態,14 ppm 總 SO₂ 遠低於感知門檻(~20-25 ppm 游離),且 Ale 酵母本來就自產 5-20 ppm。**別超過 KMS 0.5g/10L**
  - **藥劑是保險(20%),流程才是主力(80%)**:keg 三次 CO₂ purge、底部入酒不濺、頂空最小、趁鮮喝。流程沒做好,加再多藥也救不回
  - 走**強制碳酸無影響**;若改瓶內二發要小心亞硫酸會壓制疲勞酵母
- **沿用不變**:Pomona 1 包 + 純氧直投、ALDC、低氧虹吸轉桶、控溫 18-20°C、綠燈確認、趁鮮喝(碳酸完成後 1-2 週內)
- **數據**:OG **1.062-1.068**(4.5kg 穀物,清爽區)、FG **1.014-1.016**、ABV **~6.5-7.0%**、IBU ~25-30(成酒 pH 拉回後**感知苦度明顯下降**)、EBC **5-7(淺金,無 Munich)**、酒花總量 **202g**(Citra 84 / Galaxy 56 / **Mosaic 56** / Magnum 6)
- 微調:想更清爽/少絲滑 → 燕麥降到 0.3kg 或拿掉;想更濃霧 → 燕麥加到 0.8kg(同#0008,更絲滑);想更烈 → 加穀物拉 OG;想更苦 → whirlpool 往 82°C 或苦花加到 8-10g;**想更香 → DH2 加到 84g**;想顏色更深 → Munich 加到 1.4-1.5kg
