🧪 Starter SOPv2.1 修正

★ 容器選擇(v2.1 重要修正)

v2 寫的「2L 容器」是錯的——starter 培養時泡沫會佔麥汁高度 30-50%,2L 容器裝 2L 麥汁會 blow off(泡沫溢出)。正確規格:

麥汁量 最小容器 推薦容器
2L(本配方所需) 3L(勉強夠,有 blow off 風險) 4-5L(安全)

具體容器選項(任選其一)

  • 4L 廣口玻璃罐(IKEA / 特力屋 / 蝦皮儲物罐,200-400 元)— 最務實
  • 5L 硼矽酸鹽錐形瓶(實驗器材行 / 蝦皮,800-1500 元)— 一次到位
  • 4L 大泡菜罐 / 醃漬罐(家裡現成或蝦皮,200 元)— 預算最低

容器口蓋鋁箔紙(廚房用一般鋁箔),包住瓶頸但不密封,讓 CO₂ 排出+空氣交換+擋灰塵飛蟲。不要用水封、不要旋緊蓋子。

🧫 Starter 製作步驟(釀造前 1-2 天)

  1. 準備好 4-5L 容器,熱水洗淨 → Star San 浸泡 2 分鐘 → 倒出晾乾
  2. 不鏽鋼湯鍋裝 2L 水加熱,加 200g DME(乾麥芽萃取物)攪溶
  3. 煮沸 10 分鐘殺菌
  4. 冰水浴或沖冷水快速冷卻到 20°C
  5. 倒進消毒過的 4-5L 容器
  6. 直接撒入 1 包 Verdant IPA(不用水化)
  7. 鋁箔紙覆蓋容器口,包住瓶頸輕壓但不密封
  8. 常溫 18-22°C 靜置 24-36 小時,中間搖晃 2-3 次(搖前用手按住鋁箔)
  9. 看到泡沫已消退、底部有 2-3cm 酵母床 = 養成功
  10. 釀造當天整桶倒進發酵桶(連 starter 麥汁一起)
★ Starter 養成功的訊號
✓ 麥汁變混濁(細胞繁殖中)
✓ 8-12 小時後有泡沫產生
✓ 24-36 小時泡沫消退,底部有酵母床
✓ 聞起來正常麥芽香+輕微酒精/酵母味
✗ 有酸味、霉味、異味 = 污染,整桶倒掉重做(別投進發酵桶)

💊 ALDC(Maturex L)SOPv2.1 新增

★ ALDC 的作用

ALDC(α-乙醯乳酸脫羧酶)是酵素,在投酵母當下加入,會從化學源頭阻斷雙乙醯(奶油爆米花味)生成。對 Orange Glow 特別有價值,因為:

  • OG 1.078 糊精多,hop creep 啃出來的副產物(雙乙醯前驅物)也多
  • 8% ABV 酵母提前疲勞,自然清除雙乙醯能力差
  • 112g dry hop 帶進酵素多,hop creep 持續時間長
  • 雙乙醯對 NEIPA 風格致命(會蓋掉熱帶水果香)

取量方法(0.2-0.3ml 微量處理)

0.2ml 用一般注射器難取,選下面任一方式:

方法 說明
胰島素注射器(推薦) 藥局買,1ml 細分到 100 格(每格 0.01ml),取 0.2ml = 對到第 20 格,精度 ±0.02ml,單支幾十塊
稀釋法 9ml 煮沸冷卻水 + 1ml Maturex L → 10ml 稀釋液 → 取 2ml(等同 0.2ml 純 ALDC)。冷藏可放 1-2 個月

投放時機與步驟

  1. 釀造當天,麥汁冷卻到 18°C 投酵母時順便加
  2. 用胰島素注射器或稀釋液取 0.2-0.3ml Maturex L(等同稀釋液 2-3ml)
  3. 倒進消毒過的小杯子,加入發酵桶
  4. 跟整桶 Starter 一起進入發酵桶
  5. 輕微搖晃讓酵素均勻分布
  6. 蓋上水封,正常發酵

儲存

Maturex L 冷藏 2-8°C 保存,開封後 6-12 個月內最佳。100ml 一瓶可以用幾百批,單批成本約台幣 2-5 元。

注意:ALDC 不取代 D-rest,只阻斷雙乙醯生成。後段 D-rest 升溫 22°C 仍要做(讓酵母清掉其他發酵副產物),但「綠燈確認」的雙乙醯壓力大幅降低,強迫測試通過機率接近 100%。

✅ 綠燈確認 SOP(v2 已建立,維持)

必須同時滿足兩個條件才能虹吸轉桶

條件一:比重連續兩次間隔 2 天完全不動
Orange Glow 高 OG 高 ABV 的 hop creep 收尾較慢,可能要等到 Day 16-18 才打平。
條件二:強迫雙乙醯測試通過
加了 ALDC 之後這個測試應該幾乎都會過,但仍建議做一次確認。

強迫雙乙醯測試方法

  1. 取 50ml 酒樣到耐熱玻璃瓶,密封
  2. 隔水加熱:小鍋裝水加熱到 60-65°C
  3. 樣本瓶放入水中浸泡 15-20 分鐘
  4. 取出後沖冷水冷卻到室溫
  5. 開瓶聞 → 跟未加熱的樣本對比
  6. 沒有奶油爆米花味 = 通過

🚰 虹吸轉桶 SOP(v2 已建立,維持)

🔧 轉桶前 1-2 小時:準備接收 Keg

  1. Keg 洗淨、消毒、組裝完成
  2. 接 CO₂ 灌滿到 10-15 PSI → 從 PRV 拉開排掉
  3. 重複「灌滿 → 排掉」至少 3 次
  4. 最後一次灌滿後保留 5 PSI 低正壓備用

🍺 轉桶當天:執行順序

  1. 發酵桶輕輕移到操作位置(絕對不要搖晃)
  2. 接收 keg 放在比發酵桶低的位置
  3. 從 keg 液體口接管入酒 → 從底部入,避免濺射
  4. 虹吸管取酒端插入發酵桶,離桶底 2-3cm
  5. 用灌注球啟動 → 不要用嘴吸
  6. 中等流速(10L 大約 8-10 分鐘轉完)
  7. 看到沉澱層快被吸到 → 立刻停止
  8. 拔起虹吸管,keg 立刻蓋緊 → 加壓 10-12 PSI → 立刻冷藏
⚠️ DDH 最佳賞味期 2-3 週
DDH NEIPA 比一般 NEIPA 氧化更敏感(dry hop 量大、酒花精油豐富),加上虹吸轉桶溶氧比 closed transfer 高。10L 一桶兩三週要喝完,別超過 3 週。

★ v2.1 加 ALDC 的風味影響
ALDC 對 NEIPA 風味完全無感(它只攔截雙乙醯前驅物,不影響酯類、苦味、酒花表現)。所以風味預期跟 v2 完全相同,差別只在「奶油味出現的機率從『可能性中等』降到『接近零』」。換句話說,v2.1 是更穩定的 v2,不是不同風格的酒。
