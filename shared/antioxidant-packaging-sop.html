封裝端抗氧化 SOP

L-抗壞血酸 + KMS 成對使用 · 只在強制碳酸時加 · 全酒譜通用
⚠️ 第一條規則:維生素C 絕對不可單獨使用
抗壞血酸(維生素C)抓走氧氣時,副產物是過氧化氫(H₂O₂)。酒中只要有微量鐵/銅離子(自來水、器具、麥芽本來就有),H₂O₂ 就會走 Fenton 反應生成毀滅性的羥自由基 → 氧化得比不加還兇(紙板味、酒花香更快掉)。

KMS(焦亞硫酸鉀)的工作就是把 H₂O₂ 收掉。兩者是協同關係,缺一不可。
手上只有 VC、沒有 KMS → 寧可兩個都不加,改做低氧流程。

上限:KMS 不要超過 0.5 g / 10L(≈28 ppm 總 SO₂),超過才有硫味風險。

🚰 執行 SOP(轉桶時)

核心順序:先下藥 → 再 purge → 再入酒。藥劑躺在 keg 底部,酒從底部灌進來時一進來就被保護、還順便攪勻,不必事後開蓋(開蓋 = 進氧,本末倒置)。

轉桶前 1-2 小時

  1. Keg 洗淨、消毒、組裝完成
  2. 秤好 VC + KMS(依上表批量),用 20-30ml 煮沸放涼的水溶開
  3. 倒進 keg 底部
  4. 接 CO₂ 灌滿到 10-15 PSI → 從 PRV 拉開排掉,重複至少 3 次
  5. 最後一次灌滿後保留 5 PSI 低正壓備用

轉桶當天

  1. 發酵桶輕輕移到操作位置(絕對不要搖晃)
  2. 從 keg 液體口接管入酒 → 從底部入,避免濺射
  3. 虹吸管取酒端離桶底 2-3cm,看到沉澱層快被吸到就立刻停
  4. 盡量裝滿、頂空最小(頂空空氣 = 氧化來源)
  5. 立刻蓋緊 → 加壓 10-12 PSI → 立刻冷藏

🚫 什麼時候「不要」加

碳酸方式加不加原因
強制碳酸 / KEG
(本家標準)		 ✅ 加 VC + KMS 不靠酵母打氣,亞硫酸完全無影響
瓶內二發(priming 糖水) ❌ 兩個都不加 亞硫酸會壓制酵母 → 高 ABV 的疲勞酵母可能打不出氣、變扁酒(不可逆)。
而且瓶內二發本身就是抗氧化機制——二發酵母會吃掉瓶內頂空的殘氧,等於天然除氧。
VC 也不能單加(見第一條規則)。
💡 所以:瓶內二發的酒,靠酵母自己除氧就好,別加藥。要用抗氧化劑,就走強制碳酸。

👃 硫味疑慮:正常劑量聞不到

  • SO₂ 進酒後大半立刻「結合」掉。它會跟酒中的醛/酮/糖結合成亞硫酸加成物——結合態 = 無味,只有游離態才有那個「燒過的火柴」味。啤酒裡羰基化合物一堆,加進去的 SO₂ 大半當場被綁走。
  • 總量本來就低。KMS 只有 ~57% 是 SO₂ → 0.25g/10L ≈ 14 ppm 總 SO₂,游離態還要再打折。而感知門檻約 20-25 ppm 游離 SO₂。
  • 你的酒本來就有亞硫酸。Ale 酵母發酵中自然產生 5-20 ppm SO₂——過去每一批都含,只是沒人講。
亞硫酸過敏提醒:少數人(氣喘者)對亞硫酸鹽敏感。此劑量遠低於葡萄酒,自己喝沒問題,但招待客人時值得知道。

⚖️ 權重:藥劑是保險(20%),流程才是主力(80%)

不要以為加了 VC + KMS 就能免掉低氧流程。
亞硫酸跟氧的反應偏慢,它是「跟氧氣搶反應的競爭者」,不是把氧氣關在門外的盾牌——同一時間氧氣也在直接啃酒花香氣化合物。流程沒做好,加再多藥也救不回。
做法貢獻成本
Keg 三次 CO₂ purge + 底部入酒不濺 + 頂空最小~80%(真正的勝負手)免費
趁鮮喝(2-3 週內)大加分免費
VC + KMS~20%(保險)便宜
換算給你看容量其實夠:14 ppm SO₂ 理論上能吃掉 ~3500 ppb 的氧,而一次「還可以」的轉桶大約帶進 200-500 ppb。看起來綽綽有餘——但問題在速度,不在容量。這就是為什麼流程仍是主力。
