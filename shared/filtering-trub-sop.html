Orange Glow / NEIPA 完整濾渣流程

hot side 撈大渣 → cold side 溫柔轉桶 · 兩支酒(妃子起笑 / Orange Glow)通用
📌 狀態:參考筆記,尚未整合進各酒譜 SOP。等確認後再合併進 v4 / v2.2 的 whirlpool/虹吸段落,或升級為主 README 的共通核心 SOP。
核心原則:髒活在 hot side(不怕氧化)幹完,cold side(發酵後)溫柔處理不攪動。

🔥 Hot Side(煮沸後 → 進發酵桶)｜可撈可攪,不怕氧化

1. 煮沸結束 → Whirlpool

  • 同方向攪 1-2 分鐘啟動漩渦,停手
  • 靜置 15-20 分鐘,讓 trub(熱凝固物 + 酒花渣)集中到鍋底中央

2. 撈大渣(粗濾)— 趁熱撈

  • 用 304 不鏽鋼中網濾勺(15-20cm)
  • 撈掉浮在表面和上層的大塊酒花渣
  • 用前 Star San 噴或熱水燙消毒

3. 冷卻 → 細目虹吸進發酵桶(第一層細濾)

⚠️ 順序提醒:細目虹吸進發酵桶是冷卻之後才做,不要把熱麥汁直接打進桶。撈大渣(步驟 2)可以趁熱,但「入桶」這一步一定在冷卻到投酵母溫度後。
  • 先把麥汁冷卻到投酵母溫度(18-20°C,見各酒譜的「冷卻 + Whirlpool SOP」)
  • 冷卻後再虹吸:管口離鍋底沉澱 1-2cm,把集中的 trub 留鍋底
  • 這層把中小渣也濾掉

🫧 發酵階段｜濾袋裝 dry hop(可選)

4. Dry hop(單段,卡主發酵期)

  • 散投,或裝尼龍濾袋(網眼粗、裝鬆、配重沉中段)
  • 若裝袋,dry hop 時間到要取出(別泡整個發酵期,會過萃草味)

❄️ Cold Side(發酵完 → 進 Keg)｜不撈不攪,低氧優先

⚠️ cold side 不做 whirlpool、不攪、不搖。發酵是好幾天的事(加上綠燈確認的穩定期),該沉的酵母/trub 早就沉好結塊在桶底了,不需要再「靜置沉降」這一步。任何攪動只會把沉好的渣打散 + 帶進氧氣(NEIPA 大忌)。發酵完直接轉桶即可。

5. 細目虹吸轉桶

  • Keg 預先 CO₂ 驅氧 3 次
  • 虹吸管離桶底 2-3cm,留底避渣
  • 細目濾袋包管口(可選,因 hot side 已濾大渣,這層不易堵)
  • 從 keg 底部入酒,不濺射
  • 轉完立刻加壓冷藏
  • (可選)想更清可先輕度 cold crash,但本酒譜為保 haze / 香氣多半略過

6. 出酒(治本,可選)

  • 浮動 dip tube → 從上層抽酒,永遠避開 keg 底部殘渣

🧰 各階段濾渣工具對照

階段工具濾什麼
Whirlpool 後不鏽鋼濾勺浮的大渣
進發酵桶(冷卻後)細目虹吸 + 留底中小渣 + trub
Dry hop尼龍濾袋(可選)dry hop 渣
轉 keg細目虹吸 + 留底殘渣
出酒浮動 dip tube(可選)keg 底部殘渣
最低配置(夠用):不鏽鋼濾勺 + 虹吸留底。
進階(更乾淨):加細目濾袋包管口 + 浮動 dip tube。
關鍵時機:大渣 hot side 撈掉 → cold side 細目袋不易堵 → 轉桶不攪動降氧化。
