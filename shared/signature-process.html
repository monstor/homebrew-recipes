🥷 獨門製程技法

Signature Process · 原料大家都買得到,贏在製程 · 跨所有酒譜通用
核心信念:同樣的麥芽、酒花、酵母,不同人做出來差很多 —— 就像同一道菜、不同廚師。護城河不在買什麼,在怎麼做,以及「懂為什麼這麼做」。這份是從 #0007–#0009 實戰淬出、大多數家釀「不做 / 做不對」的技法。每一條都附怎麼做 · 為何贏 · 原理。

A香氣工程 — 大多家釀最輸這裡

① 雙段乾投(DH1 生物轉化 + DH2 純香)

怎麼做DH1 卡活躍發酵期投(比重降到 OG 一半)→ 酵母邊發酵邊做生物轉化;DH2 綠燈(發酵確認停)後才投、泡 2-3 天。
為何贏一般家釀單段乾投 → 香氣被活躍發酵的 CO₂ 沖走一半(CO₂ scrubbing)。DH2 在發酵停後投 = 零沖刷、純香完整留住。
原理生物轉化需要活躍酵母(DH1);揮發性香氣怕 CO₂ 沖刷(DH2)。兩個目標時機相反,所以分兩段。
出處:#0007/#0008「有做 whirlpool + 投滿乾投卻不夠香」→ 推斷是 CO₂ 沖刷,補 DH2 解決。

② 旋渦 vs 乾投「分工」,不互相取代

怎麼做Whirlpool(78°C)給「口中的果汁感/風味」;Dry hop給「鼻子的香」。兩個都做滿,別為了省酒花砍掉任一個。
為何贏一般家釀把兩者混為一談,或砍其一。砍 whirlpool → 失去口中果汁;砍 dry hop → 鼻子不香。
出處:曾為降苦把香花從 dry hop 挪去 whirlpool,發現是「用錯工具」→ 收回,兩個都做滿。

B精準控制 — 大多家釀憑感覺

③ 看比重不看日子(乾投觸發 = 重力窗口)

怎麼做DH1 觸發條件 = 比重降到「OG 一半」(活躍發酵期),不是固定 Day 3/5。依酵母速度調:Pomona 極快 → 常 Day 1-2 就到,從 Day 1 起就量。
為何贏一般家釀照酒譜「Day 3 乾投」→ 用快酵母就錯過生物轉化窗口。#0008 拖到第 3 天(已 1.016)才投,生轉化打折。
出處:Pomona 首批 #0008 三天就近終點,教訓「看比重不看日子」。

④ 煮前 OG + 秤鍋算體積(不盲煮)

怎麼做洗槽後、開煮前:折射儀量煮前 OG + 秤鍋算體積(總重−空鍋皮重)→ 算「煮到剩幾升關火」=(煮前 OG 點數 × 升數)÷ 目標點數 → 邊煮邊秤,到目標體積關火。
為何贏一般家釀盲煮、煮完才量 OG → 蒸發太多就暴衝(#0009 煮過頭 OG 衝到 1.11)。這招讓煮沸有明確終點,OG 必落目標。
配套火候:開蓋 + 滾後轉小火,蒸發控在 ~1.5L/hr(狂滾會暴蒸發)。DMS 靠「開蓋」趕、不靠猛滾。
出處:#0009 蒸發 4-5L、OG 暴衝 1.11 的血淚。

⑤ pH 雙向調整 + 每次校正 + 量糖化醪(不量水)

怎麼做投麥芽後 10-15min 取小樣、冷卻到 20-25°C 再量(熱讀偏低 ~0.3)。目標 5.2-5.4:低→加小蘇打、高→加乳酸/磷酸,兩樣都備。pH 筆每次開釀都校正。
為何贏一般家釀忽略 pH,或盲抄酒譜「加酸」。但水批次間會變:#0008 糖化醪 4.76(太酸,該加鹼)、#0009 麥汁 5.81(偏鹼,該加酸)—— 方向相反!不量就賭錯。
原理成酒 pH 決定苦味「順 or 尖銳」(#0008 成酒 3.83 太酸 → 苦咬喉)。糖化醪 pH 才有意義(水的 pH 無關,投麥芽後全變)。軟水低鹼(KH40)緩衝力弱 → 對酸鹼都敏感、少量就動。
出處:#0008 太酸 vs #0009 太鹼,證明「水會變、要雙向、要校正」。

C低氧化偏執 — 大多家釀不在乎

⑥ 全程低氧 + VC/KMS 成對(懂 Fenton)

怎麼做純氧直投(投前 60-90s,之後全程避氧)· 乾投/轉桶 CO₂ purge · 底部入酒不濺 · 頂空最小 · 轉桶時 keg 底部先下 VC + KMS(焦亞硫酸鉀/Campden)成對 · 趁鮮喝。
為何贏一般家釀濺射轉桶、不在乎氧,NEIPA 香氣幾天就掉。更關鍵:VC 絕不可單用 —— 抗壞血酸抓氧產 H₂O₂,遇鐵/銅走 Fenton 反應生成羥自由基 → 比不加更糟。KMS 負責收 H₂O₂。懂這個的家釀極少。
權重藥劑是保險(~20%),流程才是主力(~80%):purge、底部入酒、頂空最小、趁鮮。
出處:抗氧化 SOP;VC 單用助氧化的化學。

D品質關卡 — 大多家釀固定天數就裝瓶

⑦ 綠燈確認 + ALDC 化學阻斷雙乙醯

怎麼做綠燈 = 連兩次比重不動 + 強迫雙乙醯測試(取樣 60°C 水浴 15min → 聞無奶油味)通過,才轉桶。投酵母當下加 ALDC(Maturex L)從化學源頭阻斷雙乙醯生成。
為何贏一般家釀照日曆固定天數就裝瓶 → 發酵沒完(瓶炸/怪味)、或雙乙醯沒清(奶油味)。綠燈用「事實」不用「日子」。
出處:妃子起笑 hop creep 失控教訓 → 綠燈 SOP。

⑧ Hop creep 管理(第二波 creep)

怎麼做乾投帶酵素會啃糊精讓 FG 續降(hop creep)。DH2 後會有「第二波」creep → 投完 DH2 要再確認連兩次比重不動才轉桶。
為何贏一般家釀不知 hop creep → 帶著未停的發酵裝瓶 = 瓶炸;或轉桶後 keg 過碳酸。走 KEG + 綠燈可控。
出處:雙段乾投的 DH2 二次 creep;妃子起笑瓶炸路徑。

E觀念突破 — 反直覺才是真功力

⑨ 苦味「從源頭治」,不砍酒花、不靠熟成

怎麼做覺得太苦 → 修 pH(太酸會讓苦尖銳)+ 石膏(硫酸鹽放大苦)+ 趁鮮喝 + 苦花準時/濾袋/煮完撈/乾投限時撈,不是少放酒花。IBU 維持主流 25-30。
為何贏一般家釀「太苦就少放酒花」→ 連香氣一起砍掉。真兇常是 pH / 新酒 / 流程失誤,不是酒花量。
出處:#0007 熟成後苦度自行收斂到剛好,證明「過苦」大半是新酒+流程。

⑩ 苦度會隨熟成收斂,但香氣也會死 → 兩者兼顧

怎麼做不用「等熟成」磨苦(那會同時磨掉香氣)。改源頭修苦 + 走 KEG 冷藏 + 趁鮮,在香氣巔峰喝掉。
為何贏一般家釀「太苦放久一點就好」→ 苦順了、香也沒了(尤其瓶內二發室溫兩週)。看穿這個 trade-off 才是關鍵。
出處:#0007 熟成 3 週苦順但香衰。
