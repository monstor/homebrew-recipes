## 🎯 這支在試什麼

1. **Superdelic 單一品種**:鳳梨 + 甜橘 + 葡萄軟糖,硫醇前驅物高。只有它,才認得出它的味道
2. **Pomona 配對**:高生物轉化把硫醇前驅物轉成更外放的熱帶香,是 Superdelic 的最佳拍檔
3. **Maris Otter**:英系餅乾麥香 + 68°C 糖化 + 燕麥麥芽,用來對抗 Pomona 的高發酵度(#0009 在 67°C 達 88%、酒體偏薄)。#0012 orange-glow 已先用同一支基麥,所以這支的唯一新變數是 Superdelic 本身

## ⚠️ 開釀前

- **Superdelic 4 包(112g)**,貴又常缺貨 → **訂到才排釀造日**;已為成本砍掉旋渦,再砍就會動到香氣主力
- 燕麥麥芽先跟原料行問貨
- 流程照現行標準:pH 雙向、出糖回流、煮前 OG、煮沸小火、乾投看比重限時撈、綠燈用時間保證、預調液 4 ml/L、碳酸 15 PSI、水冷水溫表
